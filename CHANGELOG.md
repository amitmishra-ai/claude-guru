## 2026-06-02

### Activity Cards: reverted type label from overline back to inline title (dev request)
- **Type label is inline again** ([src/components/shared/SessionCard.tsx](src/components/shared/SessionCard.tsx)) — the activity type (Evaluation, Mentored Learning, Residency Assignment, etc.) was rendered as a separate overline eyebrow row with a type icon above the title. - **Status chip back on the title row, right-aligned** ([src/components/shared/SessionCard.tsx](src/components/shared/SessionCard.tsx)) — after the type label moved inline the chip was stranded in its own (now empty) eyebrow row above the title. Moved the chip (`rightCluster`) onto the title row, right-aligned beside the title, matching the original layout. The eyebrow row now renders only when there's an attention chip (e.g. "Late submission").
- **"Late submission" chip is now a solid primary chip** ([src/pages/Dashboard/index.tsx](src/pages/Dashboard/index.tsx), [src/pages/Components/index.tsx](src/pages/Components/index.tsx)) — swapped the light primary tint (`rgba(25, 106, 229, 0.10)` bg, `primary.main` text) for a filled primary chip (`primary.main` bg, `primary.contrastText` text).

### Completed tab: pinned "Overdue" section for Evaluator / Moderator
- **Problem** — Evaluation / Moderation activities carry a due date. If the Guru doesn't finish grading before the due date passes, the activity moves into Completed (its window closed) even though it's incomplete. These were buried in the month groups and impossible to find.
- **Pinned Overdue accordion** ([src/pages/Dashboard/index.tsx](src/pages/Dashboard/index.tsx)) — the Completed tab now pulls overdue Evaluation / Moderation activities out of the month groups and into a dedicated **Overdue** accordion pinned to the very top. Red-highlighted summary (declined-status tokens) with an error icon, a count badge of how many are overdue, and a "Past due date with grading unfinished" hint. **Collapsed by default** so it reads as an at-a-glance flag; expanding reveals each overdue card with an `Overdue` chip, the partial grading progress (e.g. `9 / 15 graded`), and a CTA to resume (`Evaluate` for Evaluation; `Discussion Question` + `Grade` for Moderation). Only appears for the Evaluator / Moderator personas (the only roles whose activities carry these due dates).
- **Data model** — added an optional `overdue?: boolean` to `Session` ([src/lib/types.ts](src/lib/types.ts)); `isOverdueActivity()` helper ([src/lib/helpers.ts](src/lib/helpers.ts)) gates on type + flag; `getActivityStats(..., { overdue: true })` ([src/lib/activity-stats.ts](src/lib/activity-stats.ts)) returns partial (graded < submissions) figures. Demo data: `eval6`, `eval7`, `mod5` are completed-but-overdue (due before the demo "today" of 21 Apr 2026).
- **Components page** ([src/pages/Components/index.tsx](src/pages/Components/index.tsx)) — added `Evaluation - Overdue` and `Moderation - Overdue` reference cards plus a reusable `CHIP_OVERDUE`, keeping the source of truth in sync.
- **Spacing fix** ([src/pages/Dashboard/index.tsx](src/pages/Dashboard/index.tsx)) — the Overdue accordion and the first month group were touching: each accordion zeroes its margin when expanded (`&.Mui-expanded { m: 0 }`), which also wiped the `Stack spacing` gap (margin-based) against its neighbour. Switched the Completed list `Stack` to `useFlexGap` so the gap comes from CSS `gap` and survives the per-accordion margin reset.
- **More completed demo data** ([src/data/demo-sessions.ts](src/data/demo-sessions.ts)) — added settled (fully graded) completed activities so the Completed tab spans multiple month groups: `eval8` (Feb), `eval9` (Jan) for Evaluator; `mod6` (Feb), `mod7` (Jan) for Moderator. Added learner ratings for `eval8` and `mod6` so they show stars + Feedback.
