*Guru Dashboard — Completed Tab: Links & Actions by Activity Type*

─────────────────────────────────────
*1. RESIDENCY*

_On the card:_
• Course name → LMS course page link
• "Combined session" badge (if multi-batch)
• Star rating widget + numeric score (e.g. 4.2/5) — shown when rating is available
• *"Detailed Feedback"* button (shown alongside the rating)
• If no rating yet → _"Gathering feedback!"_ (no button shown)

_On clicking Detailed Feedback:_
• Batch name + Course name
• No. of feedback responses received
• Avg. Course Rating (stars + score out of 5)
• Pie chart — rating distribution (5-star / 4-star / 3-and-below)
• Bar chart — detailed breakdown
• Student comments — tabbed by rating (5 star / 4 star / 3 & below)

─────────────────────────────────────
*2. ONLINE SESSION*

_On the card:_
• Course name → LMS course page link (if course linked)
• "Online Session Recording" → session recording page (if available)
• Star rating widget + numeric score (e.g. 4.2/5) — shown when rating is available
• *"Detailed Feedback"* button (shown alongside the rating)
• "Share Feedback" link (comment icon) → mock interview feedback form (mock interviews only, if feedback not yet submitted)
• "secondary" badge if guru was the secondary facilitator
• If no rating + session ≤ 30 days → _"Gathering feedback!"_
• If no rating + session > 30 days → _"No feedback collected"_

_On clicking Detailed Feedback:_
• Batch name + Session title
• No. of feedback responses received
• Avg. Session Rating (stars + score out of 5)
• Pie chart — rating distribution (5-star / 4-star / 3-and-below)
• Bar chart — detailed breakdown
• Student comments — tabbed by rating (5 star / 4 star / 3 & below)

─────────────────────────────────────
*3. EVALUATION (Assignment)*

_On the card:_
• Assignment name → LMS SpeedGrader page link
• Star rating shown *directly on card* using star icons (no numeric score)
• *"Detailed Feedback"* button
• If no rating → _"Gathering feedback!"_

_On clicking Detailed Feedback:_
• Assignment name + Course name
• Star rating out of 5
• If rating < 5 → feedback option tags + free-text comments
• If rating = 5 → positive feedback aspects with tick icons

─────────────────────────────────────
*4. MODERATION (Discussion Question)*

_On the card:_
• Assignment name → LMS SpeedGrader page link
• Star rating shown *directly on card* using star icons (no numeric score)
• *"Detailed Feedback"* button
• If no rating → _"Gathering feedback!"_

_On clicking Detailed Feedback:_
• Assignment name + Course name
• Star rating out of 5
• If rating < 5 → feedback option tags + free-text comments
• If rating = 5 → positive feedback aspects with tick icons

─────────────────────────────────────
*5. CAPSTONE PROJECT*

_On the card:_
• No course/activity link
• *"View Student Progress"* button → loads student feedback & progress inline
• Tooltip on date: all milestone dates (start, synopsis, interim, final report, presentation)

─────────────────────────────────────
*6. CV REVIEW*

_On the card:_
• "View Reviewed CV" → opens student's resume/CV document
• No feedback, no rating, no drilldown

─────────────────────────────────────
*NOTE: Payment info (part-time gurus only)*
All activity types show the following at the bottom of the card when payment has been processed:
_Payment Processed, TXN ID: [id]_

─────────────────────────────────────
*KEY DIFFERENCE: How ratings are shown*

Residency & Online Session:
→ Star widget + numeric score (e.g. 4.2/5) on card
→ "Detailed Feedback" button shown *alongside* the rating

Evaluation & Moderation:
→ Only star icons on card (no numeric score)
→ "Detailed Feedback" button shown *below* the stars

Capstone & CV Review:
→ No rating shown
